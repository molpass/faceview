> *"상(相)은 마음에서 생기고, 운명은 스스로 만든다. 관상·손금·골상·체상은 모두 인생 궤적의 드러남이다."*

## 사용

### 기본 사용법

1. **사진을 업로드하고 분석 유형을 설명**:
   ```
   이 관상 좀 봐줘 [사진 업로드]
   ```

2. **또는 사진을 바로 업로드**:
   ```
   [사진 업로드]
   스킬이 자동으로 사진 유형을 인식해 분석합니다
   ```

### 지원하는 분석 유형

| 유형 | 설명 | 사진 요구사항 |
|------|------|---------|
| **관상** | 이목구비, 삼정, 십이궁, 기색 분석 | 정면 또는 측면 얼굴 사진 |
| **손금** | 손금, 손가락 형태, 손바닥 언덕, 색택 분석 | 손바닥 정면 사진 |
| **골상** | 두개골, 체골, 구골(九骨) 구조 분석 | 골격 윤곽이 보이는 사진 |
| **체상** | 체형, 자세, 기질 분석 | 전신 또는 반신 사진 |

## 기능 특징

### 지원하는 상술 유형

| 유형 | 분석 항목 | 규칙 출처 |
|------|---------|---------|
| **관상** | 이목구비, 삼정, 십이궁, 기색, 골격 | 《마의신상》《유장상법》《신상전편》 |
| **손금** | 손금, 손가락 형태, 손바닥 언덕, 색택, 무늬 | 《신상전편》《수경신상》 |
| **골상** | 두개골, 체골, 구골(九骨) 구조 | 《태청신감》《인륜대통부》 |
| **체상** | 체형, 자세, 기질, 걸음걸이 | 《빙감》《신상전편》 |

### 분석 보고서 구조

각 분석 보고서는 다음 부분을 포함합니다:

1. **기본 정보**: 상술 유형, 분석 시각
2. **특징 인식**: 사진에서 인식한 핵심 특징
3. **성격 특성**: 주요 성격 성향, 장단점
4. **능력 성향**: 잘하는 분야, 적합한 직업
5. **운세 분석**: 시기별 또는 항목별 운세 분석
6. **건강 팁**: 건강 관련 관찰과 조언
7. **발전 조언**: 상술 분석에 기반한 실용적 조언

### 기술 원리

```
사진 업로드 → 이미지 유형 인식 → 규칙 베이스 호출 → 특징 추출 → 종합 분석 → 보고서 생성
```

1. **이미지 유형 인식**: 관상/손금/골상/체상 자동 판별
2. **규칙 베이스 호출**: 해당 상술 규칙 파일(고전 상서 기반) 읽기
3. **특징 추출**: 시각 분석 도구로 핵심 특징 추출
4. **종합 분석**: 규칙 지식을 결합한 다차원 분석
5. **보고서 생성**: 면책 조항이 포함된 구조화된 분석 보고서 출력

### ⚠️ 중요 안내

- **본 분석은 문화적 참고와 오락용일 뿐**: 상술은 전통문화에 속하며, 현대 과학은 그 예측 능력을 아직 입증하지 못했습니다
- **이성적으로 받아들일 것**: 인생의 길은 주로 개인의 노력과 선택에 달려 있습니다
- **단정적 결론을 내리지 않음**: 모든 분석은 확률적 참고이며 절대적 운명이 아닙니다
- **건강 팁은 참고용일 뿐**: 건강 문제가 있으면 전문 의사와 상담하세요

### 📋 사용 제한

- 구체적 사건(예: "언제 결혼", "언제 부자가 되는지")을 예측하지 않음
- 정치적으로 민감한 주제를 다루지 않음
- 미신적 색채를 조장하지 않음
- 모든 분석 보고서 말미에 면책 조항 포함

- **프라이버시**: 타인의 사생활이 포함된 사진은 업로드하지 마세요

## 자주 묻는 질문

### Q: 분석 결과가 정확한가요?
**A**: 상술은 전통문화의 일부로 참고할 수 있으나 맹신해서는 안 됩니다. 상술의 예측 능력에 대해 현대 과학은 아직 결론을 내리지 못했습니다. 분석 결과를 오락 및 문화적 참고로 삼아 이성적으로 받아들이기를 권합니다.

### Q: 어떤 유형의 사진을 업로드할 수 있나요?
**A**: 얼굴, 손바닥, 전신 등 신체 부위 사진을 지원합니다. 사진은 또렷하게 보여야 하며 흐림·가림·과도하게 어두운 조명 등을 피해야 합니다.

### Q: 분석에 얼마나 걸리나요?
**A**: 보통 몇 초에서 십수 초 내에 분석이 완료됩니다.

### Q: 사진을 여러 번 업로드해 분석할 수 있나요?
**A**: 가능합니다. 각 분석은 독립적이며, 서로 다른 사진을 여러 번 업로드해 분석할 수 있습니다.

### Q: 분석 결과가 저장되나요?
**A**: 저장되지 않습니다. 각 분석은 실시간으로 이루어지며 사진이나 분석 결과를 저장하지 않습니다.

### Q: 어떤 상술 유형을 지원하나요?
**A**: 현재 관상, 손금, 골상, 체상 네 가지를 지원합니다. 향후 더 많은 유형으로 확장될 수 있습니다.

## 맺음말

상술은 옛사람들이 인간과 자연을 관찰한 지혜의 결정체입니다.

그것은 미신이 아니라 체계화된 경험의 총결입니다. 관상으로 성격을, 손금으로 성향을, 골상으로 격국을, 체상으로 기질을 본다 — 이는 모두 선조들이 '인간'이라는 복잡한 시스템을 이해한 하나의 방식이었습니다.

물론 현대 과학은 운명이 결코 겉모습에 쓰여 있지 않다고 말합니다.

당신의 성격, 능력, 운세는 더 많은 부분이 당신의 선택, 노력, 그리고 인연에 달려 있습니다. 상술 분석은 흥미로운 참고이자 전통문화의 매력을 엿보는 창이 될 수 있지만, 결코 인생의 나침반은 아닙니다.

진정한 '개상(改相)'은 외형의 꾸밈이 아니라 내면의 수양에 있습니다.

《빙감》에서 이르길, "온몸의 정신은 두 눈에 깃들고, 온몸의 골상은 얼굴에 깃든다." 정신과 기질이야말로 상술의 궁극적 추구입니다.
